# Cerelytic Chess v3.0.0

Cerelytic Chess v3 expands the original offline board into a complete local chess application.

## Highlights

- New branded Home dashboard and five-destination navigation shell
- Device-local profiles, avatars, statistics, profile switching, and optional PIN lock
- Packaged local Stockfish play plus pass-and-play
- Game setup for side, engine strength, clock, hints, and legal markers
- Five offline puzzles with progress tracking
- Saved history, replay, and local analysis
- Smooth touch/drag interactions, haptics, hints, clocks, promotions, board flip, undo, and resume
- Amber check state and red checkmate result presentation
- Original Cerelytic mark, launcher icon, avatars, icons, and Staunton pieces
- Fully offline operation with no Android permissions

## Compatibility

- Android 10 or later
- ARM64 devices
- Package: `com.cerelytic.knight`

An existing installation can update in place only when the new APK is signed with the same key as the installed build.
