# Framilton Chess v3.0.0

Framilton Chess v3 is a complete local-first Android chess application.

## Highlights

- Framilton-branded Home, launcher, splash, Android metadata, and release artifacts.
- Device-local profiles, avatars, statistics, profile switching, and optional PIN lock.
- Packaged local Stockfish play plus pass-and-play.
- Side, engine strength, clocks, hints, and legal-move controls.
- Five offline puzzles with progress tracking.
- Saved history, replay, and local analysis.
- Touch/drag interactions, haptics, promotions, board flip, undo, and resume.
- Amber check state and red checkmate result presentation.
- Fully offline operation with no Android permissions.

## Compatibility

- Android 10 or later.
- ARM64 devices.
- Package: `com.framilton.knight`.
- Artifact: `FramiltonChess-v3-offline-arm64.apk`.

This package namespace is a clean Framilton identity boundary. It installs as a separate application from builds distributed under another package ID.
