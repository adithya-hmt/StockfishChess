# NativeActivity packaging template

`AndroidManifest.xml` and `resources.arsc` are adapted from the public `cnlohr/rawdrawandroid` NativeActivity sample APK and structurally patched at build time. The rawdrawandroid Makefile identifies that project as MIT/X11 or NewBSD licensed at the user's choice.

The launcher icon in `res/mipmap/icon.png` is original Framilton Chess artwork generated for this project. It is not copied from Chess.com, Stockfish, or the upstream packaging template.
