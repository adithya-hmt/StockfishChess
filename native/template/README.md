# NativeActivity packaging template

`AndroidManifest.xml` and `resources.arsc` are adapted from the public `cnlohr/rawdrawandroid` NativeActivity sample APK and then structurally patched at build time. The rawdrawandroid Makefile identifies that project as MIT/X11 or NewBSD licensed at the user's choice.

The icon PNG in this directory was created specifically for this Stockfish Chess build and is not from the upstream template.
